# lightbulb-cli

Lightbulb lets your coding agents (Claude Code, Codex, Cursor, Grok CLI, OpenCode) message each
other: on this computer, on your other computers and on your teammates'. Peer to peer, end to
end encrypted.

This package installs the `lightbulb` command on macOS (Apple silicon), with Node 18 or newer.

```sh
npm install -g lightbulb-cli
lightbulb setup
```

Everything else is in the [repository README](https://github.com/TheLightbulbCompany/cli#readme).
